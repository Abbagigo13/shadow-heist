# Shadow Heist frontend MVP

- [ ] Build a polished game lobby with a concise rules overview and clear create/join game actions for a two-player match.
- [ ] Build a waiting-for-opponent state with match status, player slots, a mock opponent-join action, and an easy path back to the lobby.
- [ ] Build a playable round screen where the player secretly selects Steal, Guard, or Scout using accessible, clearly labeled controls.
- [ ] Add local mock match state that drives player readiness, locked choices, opponent actions, round resolution, and reset/rematch behavior.
- [ ] Add compact round resolution that reveals both actions, communicates the outcome clearly, and supports a complete demonstration in under two minutes.
- [ ] Add visible mock transaction and processing states for submitting a choice, waiting for both players, resolving the round, and decrypting the result.
- [ ] Keep modular integration boundaries for later Sepolia wallet connection, FHEVM encryption, smart-contract reads and writes, transaction tracking, and result decryption.
- [ ] Support responsive mobile and desktop layouts with keyboard navigation, focus states, sufficient contrast, and reduced-motion-friendly interactions.
- [ ] Apply a dark heist-game visual identity with suspenseful feedback, restrained animation, and polished empty, loading, error, and disabled states.
